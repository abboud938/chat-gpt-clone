Chat GPT Clone
This project is a clone of Gemini-AI with a custom Chat-GPT UI, developed using modern web technologies. The app integrates the capabilities of OpenAI's GPT for natural language generation, providing an interactive chat experience.

Features
Custom user interface for an enhanced chat experience.
Seamless interaction with OpenAI's GPT model.
Real-time text generation and response.
Responsive design for use on desktop and mobile devices.
Technologies Used
Next.js: For server-side rendering and fast, scalable web applications.
Tailwind CSS: For styling and creating a responsive UI.
JavaScript/TypeScript: For dynamic and efficient scripting.
OpenAI GPT: Integrated for AI-driven responses.
